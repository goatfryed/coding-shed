# Implement Change

Implement a requested or planned change within its agreed requirements and technical boundaries.
Follow applicable decision records.

## Grounding
Ground implementation choices in current source contracts and API documentation.
Use the project's dependency versions when researching documentation.

## Verification
Keep verification focused on the change and its risks, including agreed checks.
For artifacts the user runs directly, perform a sanity check by default;
add tests when requested or justified by complexity and risk.
