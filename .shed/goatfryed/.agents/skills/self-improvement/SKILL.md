# Self-Improvement

## Reflection

- Record consequential misunderstandings, pitfalls, and revelations in `introspection.md` in the session-artifact directory defined by project instructions. Preserve existing entries.
- Include session, date, context, evidence, and lessons or open questions. Distinguish observations from hypotheses.

## Evidence

- For repository evidence, identify the repository and relevant commit. Distinguish committed content from working-tree or intermediate states.
- Identify applicable instructions by source path and version where known; include concise excerpts when they explain the behavior or conflict. Mark unverified versions and historical states explicitly.

## Improvement proposals

- When evidence indicates a clear benefit, propose instruction or workflow changes when asked or after the main work.
- Tie proposals to the observed problem and expected benefit. Treat them as choices for the user, not authorization to change instructions.
